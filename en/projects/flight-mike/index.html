Overview

A travel search tool connecting flight providers, destination exploration, and hotel comparisons.

Problem

Travel planning requires repeated comparisons across flights, destinations, and hotels.

Solution

A Next.js frontend connects to an Express proxy and providers, with a Chrome extension entry point; no live prices were queried in this review.

My Role

Travel search flows, result comparisons, and frontend/backend provider integration.

Architecture Context

Web/Chrome extension → Express API → Amadeus/RapidAPI → flight and hotel results

Capabilities

  • Single/return and multi-city search
  • Destination exploration and hotel comparison
  • Chrome extension and price alert code

Tech Stack

  • Next.js
  • Express
  • Amadeus
  • Chrome MV3
