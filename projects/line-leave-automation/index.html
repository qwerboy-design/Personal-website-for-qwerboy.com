LINE 請假自動化

用 LINE 提交與確認請假，串接行事曆、請假紀錄與管理通知。

狀態: active · 未經獨立查證

概覽

用 LINE 提交與確認請假，串接行事曆、請假紀錄與管理通知。

問題

請假訊息、行事曆與人員紀錄分散，人工轉錄容易產生重複或遺漏。

解法

以 LINE 提交申請並由本人確認；Power Automate 驗證身分與資料後建立 Outlook 事件，依人員條件更新 Excel，並保留狀態與失敗步驟。

我的角色

請假流程設計、欄位契約、跨系統自動化與維運移轉整理。

架構脈絡

LINE → Webhook／Power Automate → SharePoint 身分與請假狀態 → Outlook／條件式 Excel → 通知

能力範圍

  • 身分綁定與請假確認
  • Outlook 行事曆與條件式 Excel 紀錄
  • 事件去重、錯誤追蹤與補償流程

技術棧

  • LINE Messaging API
  • Power Automate
  • SharePoint
  • Outlook / Excel
