狀態: development · 未經獨立查證

概覽

整合航班搜尋與票價整理，協助比較不同來源的旅行選項。

問題

跨來源航班資料不一致，旅客需要清楚比較價格、時間與限制。

解法

提供搜尋工作區與供應商管理層，整理結果與快照。Daily Watch 仍受功能開關控制，排程及通知需獨立驗證。

我的角色

旅行搜尋體驗、來源比較與功能閘門設計。

架構脈絡

搜尋條件 → 供應商管理／快取 → 正規化與排序 → 搜尋工作區／價格快照

能力範圍

  • 航班搜尋工作區
  • 多來源結果正規化與排序
  • 價格快照與 Daily Watch 架構

技術棧

  • Next.js
  • TypeScript
  • SQLite
  • Flight APIs
