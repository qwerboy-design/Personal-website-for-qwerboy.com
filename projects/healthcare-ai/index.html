Healthcare AI Assistant

整合 AI 對話、FHIR 資料匯入與隱私遮罩，協助整理醫療資訊。

狀態: development · 未經獨立查證

概覽

整合 AI 對話、FHIR 資料匯入與隱私遮罩，協助整理醫療資訊。

問題

醫療資料格式分散，導入 AI 時也需要保護個資與控制使用權限。

解法

將身分驗證、對話、FHIR 匯入、PHI 遮罩與模型設定整合。報告草稿輔助受功能開關控制，保留人工審閱。

我的角色

醫療資訊工作流程設計、產品需求與 AI／資料整合。

架構脈絡

Next.js 介面 → 驗證與隱私處理 → 對話／FHIR API → Supabase 與 LLM

能力範圍

  • AI 對話與歷史紀錄
  • FHIR 匯入與預覽
  • 隱私遮罩與模型切換

技術棧

  • Next.js
  • Supabase
  • FHIR
  • Ollama
