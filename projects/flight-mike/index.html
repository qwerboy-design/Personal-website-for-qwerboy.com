Flight Mike

串接機票來源、探索目的地與住宿比價的旅行搜尋工具。

狀態: development · 未經獨立查證

概覽

串接機票來源、探索目的地與住宿比價的旅行搜尋工具。

問題

旅行規劃需要在機票、目的地與住宿之間反覆切換與比較。

解法

以 Next.js 網頁串接 Express 代理與搜尋供應商，另提供 Chrome 擴充入口；本次未查詢即時價格。

我的角色

旅行搜尋流程、結果比較與前後端供應商整合。

架構脈絡

Web／Chrome 擴充 → Express API → Amadeus／RapidAPI → 航班與住宿結果

能力範圍

  • 單程／來回與多城市搜尋
  • 目的地探索與住宿比較
  • Chrome 擴充與價格提醒程式

技術棧

  • Next.js
  • Express
  • Amadeus
  • Chrome MV3
