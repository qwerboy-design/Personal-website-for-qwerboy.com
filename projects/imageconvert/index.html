把旅行影像與產品介紹整理成直式短影音的製作工作區。

狀態: prototype · 未經獨立查證

概覽

把旅行影像與產品介紹整理成直式短影音的製作工作區。

問題

照片與影片素材需要整理成適合社群閱讀節奏的直式內容。

解法

以 HyperFrames 和 HTML 場景編排旅行素材及產品說明，保留可重用的設計與輸出流程。

我的角色

旅行與自媒體內容腳本、視覺編排及短影音流程。

架構脈絡

照片／影片素材 → HTML／GSAP 場景 → HyperFrames 預覽／渲染 → 短影音

能力範圍

  • 旅行與產品短片場景
  • HTML／GSAP 動畫排版
  • 預覽、檢查與影片輸出流程

技術棧

  • HyperFrames
  • HTML / CSS
  • GSAP
  • FFmpeg
