從咖啡商品、規格與購物車到訂單通知的一站式訂購平台。

狀態: development · 未經獨立查證

概覽

從咖啡商品、規格與購物車到訂單通知的一站式訂購平台。

問題

咖啡訂購需要串起顧客選購、訂單紀錄與店家管理，減少重複處理。

解法

以前台商品選購與後台商品管理為核心，訂單 API 建立紀錄後觸發 Email 與 N8N 流程。

我的角色

顧客訂購流程、店家管理介面與通知自動化整合。

架構脈絡

商品／購物車 → 訂單 API → Supabase → N8N／Resend 通知

能力範圍

  • 商品規格與庫存顯示
  • 購物車與訂單建立
  • 後台管理及 Email／N8N 通知

技術棧

  • Next.js
  • Supabase
  • N8N
  • Resend
